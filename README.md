# Advanced Python Keylogger

A feature-rich and modular Python keylogger designed for educational purposes and authorized security research.

## Features

- Keystroke logging with contextual awareness
- Smart text buffering
- Active window and process tracking
- Browser URL extraction (Chrome, Firefox, Edge)
- Login, username, and password field detection
- Clipboard monitoring
- Mouse click logging
- Screenshot capture
- System information collection
- AES-256-GCM encryption
- zlib compression
- SMTP, Telegram, and Webhook delivery
- Multi-email fallback support
- Log rotation and buffered logging
- Registry persistence
- Single-instance enforcement
- Optional anti-debugging
- Virtual machine detection
- Thread renaming
- Self-deletion
- Heartbeat markers
- Crash logging
- Automatic cleanup
- Configurable settings
- Timestamped log entries
- Support for special and modifier keys

## Requirements

- Python 3.10+
- Windows 10/11
